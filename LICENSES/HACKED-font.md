`SoundGuide/hacked.ttf` is the HACKED typeface by David Libeau, downloaded from [dafont.com/hacked.font](https://www.dafont.com/hacked.font). It is used by the 3D web viewer.

The font's ReadMe grants use on a CC-BY basis: a published creation that uses the font must credit the source by linking <http://bit.ly/WatchDogsFont>. The viewer page carries that credit in its bottom-right corner; keep it if you change the page.

The font is a fan-made typeface in the style of the Watch Dogs title lettering. It is not an Ubisoft asset, and the ReadMe's grant covers only the author's own work.
